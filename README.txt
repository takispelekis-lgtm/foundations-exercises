ΔΙΑΔΡΑΣΤΙΚΕΣ ΑΣΚΗΣΕΙΣ ΘΕΜΕΛΙΩΣΕΩΝ
=================================

Άνοιγμα
-------
Διπλό κλικ στο index.html (ή απευθείας bearing.html / settlements.html / piles.html).
Δεν χρειάζεται εγκατάσταση ή σύνδεση στο internet. (Με internet φορτώνουν και οι
γραμματοσειρές Fira Sans / STIX Two· χωρίς internet χρησιμοποιούνται οι γραμματοσειρές
του συστήματος.)

Χρήση στην τάξη
---------------
- Βέλη δεξιά/αριστερά: επόμενο / προηγούμενο βήμα της λύσης. Home/End: αρχή/τέλος.
- P: λειτουργία παρουσίασης (μεγάλα γράμματα, χωρίς μενού). F: πλήρης οθόνη.
- "Αυτόματα": αυτόματη εναλλαγή βημάτων. "Όλα": εμφάνιση ολόκληρης της λύσης.
- Ρυθμιστικά "Δεδομένα – πειραματιστείτε": αλλάζουν τα δεδομένα της άσκησης και
  όλα τα βήματα, το σχήμα και το αποτέλεσμα επανυπολογίζονται. "Τιμές εκφώνησης"
  επαναφέρει τα αρχικά.
- Το μενού "Τυπολόγιο, πίνακες και διαγράμματα" έχει τους τύπους κάθε ενότητας.

Επεξεργασία / προσθήκη ασκήσεων
-------------------------------
Ο πηγαίος κώδικας είναι στον φάκελο src:
  engine.js / engine.css   κοινή μηχανή (βήματα, ρυθμιστικά, σχήματα, τυπολόγιο)
  ex_bearing.js            ασκήσεις φέρουσας ικανότητας
  ex_settle.js             ασκήσεις καθιζήσεων
  ex_piles.js              παραδείγματα πασσάλων
  build.js                 παράγει τα τελικά html:  node build.js
  test.js                  έλεγχος υπολογισμών:     node test.js ex_bearing.js
Κάθε άσκηση είναι ένα αντικείμενο με: εκφώνηση, δεδομένα (ρυθμιστικά), compute()
για τους υπολογισμούς, figure() για το σχήμα SVG και steps[] για τα βήματα.
Μετά από αλλαγές στον φάκελο src τρέξτε "node build.js" (απαιτεί Node.js).
